01 / Introduction

Project overview

RideConnect aims to make commuting more efficient through shared rides. The group's Agile Team Charter identifies user registration, driver trip offers, passenger ride search and booking, trip information, and seat availability as core requirements. The application screenshots supplied for this portfolio illustrate driver login, registration, ride creation, rider requests, acceptance and ride completion.

Project objective

Reduce the inconvenience and cost of commuting by helping people travelling in similar directions share transport.

My documented role

Wireframes Designer — creating key screen layouts and supporting usability. The exact designs I personally created still need to be confirmed.

Assessment structure

Five Agile components, each marked out of 20: 10 marks for evidence and 10 for individual reflection.

Portfolio status: initial evidence is documented below. Some original records and my individual reflections still need verification. Planned features are not presented as tested functionality.

User Stories and Tasks

Evidence · 10 marks

Illustrative story: As a driver, I want to post a ride with its route, departure time and seat count so passengers can find available transport.

Potential tasks: design offer form, validate fields, implement offer submission, and test seat limits. These tasks must be checked against original group records.
