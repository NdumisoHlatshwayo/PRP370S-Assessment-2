User stories

These stories are design-oriented examples derived from the project's documented feature requirements. They are not presented as verified original Trello user-story records.

Passenger journey

Find an available ride

As a passenger, I want to search for available carpools so that I can find a ride to my destination.

Illustrative breakdown: define search fields, design the search interface, implement search and check the results.

Driver journey

Offer a ride

As a driver, I want to post a trip with a departure time and available seats so that passengers can request to join.

Illustrative breakdown: design the ride-offer form, validate inputs, submit the offer and check seat availability.

Individual reflection

I shared Figma wireframes with the group for feedback on 23 May 2026 and later volunteered for the UX Design sprint area on 23 July 2026. These activities helped me think about the different journeys drivers and passengers need to follow in RideConnect.

The Trello tasks on identifying users, mapping journeys and creating wireframes demonstrate how a broad application idea can be divided into manageable design activities. I learned to begin with the user's goal, make navigation understandable, and seek feedback before implementation. This reflection describes my documented involvement; it does not claim that I completed every Trello task or personally implemented every screen.
