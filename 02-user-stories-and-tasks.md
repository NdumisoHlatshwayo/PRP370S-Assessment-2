# 2. User Stories and Tasks

## Evidence

The completed Agile Team Charter describes proposed capabilities: user login, posting trips, searching for carpools, joining rides, and viewing available seats. **These are source requirements, not verified original user-story records.**

### Draft examples to check against actual group work

- *As a passenger, I want to search for available carpools so that I can find a ride to my destination.*
- *As a driver, I want to post a trip with a time and seat count so that passengers can request to join.*

Possible tasks for the passenger story: design search wireframe; define search fields; implement trip search; test results. These tasks are **illustrative suggestions**, not claims that the team performed them.

The export does not, by itself, prove that these cards were originally written in the standard *As a [role], I want [goal], so that [benefit]* user-story format or that each had formal acceptance criteria.
